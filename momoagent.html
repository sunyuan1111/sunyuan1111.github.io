MomoAgent

从零构建的高负载智能机械臂，以及可持续扩展的真实机器人软件栈。

GitHub ↗

我解决的问题

一个能用于研究与原型验证的机械臂，不只需要末端能动，还需要可靠的控制、标定、感知、交互和部署路径。MomoAgent 围绕这一整条链路，将硬件能力从一次性演示变成可复用的系统能力。

系统工作

  • 完成舵机控制、主从臂通信与标定流程。
  • 打通相机传输、Qt 交互与机器人控制服务。
  • 接入 LeRobot 策略部署与多模态 Agent 执行。
  • 将常用硬件能力封装为服务与 SDK，便于后续迭代。

系统构成

Hardware高负载机械臂、相机、末端执行器
Control舵机、通信、标定、运动控制
InterfaceQt 桌面交互、相机流与可视化
IntelligenceLeRobot 策略与多模态 Agent
