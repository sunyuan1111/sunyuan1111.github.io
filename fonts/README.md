# Web fonts

- `cef-title-subset.woff2`: subset of CEF Fonts CJK, used only for Chinese display headings. Source: https://github.com/Partyb0ssishere/cef-fonts-cjk
- `noto-serif-sc-regular-subset.woff2`: subset of Noto Serif CJK SC Regular, used for long-form Chinese text.
- `noto-serif-sc-bold-subset.woff2`: subset of Noto Serif CJK SC Bold, used for emphasized Chinese text.

All files are subsetted to the characters used by this website. See `OFL-CEF.txt` and `OFL-NOTO.txt` for licenses.
